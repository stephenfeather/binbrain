# BinBrain

Physical storage bin inventory management with AI-assisted cataloging. Photograph your bins, let a local vision model identify the contents, and search your inventory semantically.

## Overview

BinBrain helps you track what items are in which physical storage bins. The core workflow:

1. Label physical bins with QR codes (generated by the included script)
2. Photograph bin contents and upload them via the API
3. Run AI vision analysis to get item suggestions from photos
4. Confirm suggestions to create inventory records
5. Search inventory semantically — "small screws" matches "M3 fasteners"

## Tech Stack

| Layer | Technology |
|-------|------------|
| API | FastAPI (Python 3.12) |
| Database | PostgreSQL 17 + pgvector |
| Embeddings | fastembed (BAAI/bge-small-en-v1.5, local CPU) |
| Vision AI | Ollama (local, default model: `qwen3-vl:4b`) |
| Containerization | Docker Compose |
| Package Manager | uv |

## Prerequisites

- Docker and Docker Compose
- [Ollama](https://ollama.ai/) running on the host with a vision model loaded:
  ```bash
  ollama pull qwen3-vl:4b
  ```

## Setup

1. Create a `.env` file in the project root:
   ```
   POSTGRES_PASSWORD=your_password_here
   ```

2. Start all services:
   ```bash
   docker compose up -d
   ```

   This starts:
   - `binbrain_db` — PostgreSQL 17 with pgvector on the internal network
   - `binbrain_api` — FastAPI application at `http://localhost:8000`

   The database schema initializes automatically on first start.

## Configuration

All settings are passed as environment variables to the `api` service (configurable in `docker-compose.yml`):

| Variable | Default | Description |
|----------|---------|-------------|
| `DATABASE_URL` | *(required)* | PostgreSQL connection string (psycopg3 format) |
| `POSTGRES_PASSWORD` | *(required)* | Set in `.env`, used by both containers |
| `PHOTO_DIR` | `/data/photos` | Filesystem path for uploaded photos |
| `EMBED_MODEL` | `BAAI/bge-small-en-v1.5` | fastembed model for text embeddings |
| `OLLAMA_URL` | `http://localhost:11434` | Ollama API base URL |
| `OLLAMA_VISION_MODEL` | `qwen3-vl:4b` | Default vision model for photo analysis |
| `OLLAMA_MAX_IMAGE_PX` | `1280` | Max pixels on longest side before downscaling |
| `SUGGEST_MATCH_THRESHOLD` | `0.85` | Cosine-similarity floor for auto-suggesting an existing catalogued item on photo upload |

## API Endpoints

All responses include `"version": "1"`. Errors follow a consistent shape:
```json
{"version": "1", "error": {"code": "...", "message": "...", "request_id": "..."}}
```

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/health` | Health check; verifies DB connectivity and reports embed model |
| `POST` | `/ingest` | Upload photos for a bin (multipart: `bin_id` + `photos[]`) |
| `POST` | `/items` | Create/upsert an item with optional bin association |
| `POST` | `/associate` | Associate an existing item with a bin |
| `POST` | `/bins/{bin_id}/add` | Add an item and/or photos to a bin in one request |
| `GET` | `/bins` | List all active bins with item/photo counts |
| `GET` | `/bins/{bin_id}` | Get a bin's items and photos |
| `GET` | `/photos/{photo_id}/suggest` | Run vision model on photo, return matched item suggestions |
| `POST` | `/photos/{photo_id}/detect` | Run object detection on photo |
| `GET` | `/photos/{photo_id}/groups` | Get detection groups for a photo |
| `POST` | `/photos/{photo_id}/confirm` | Confirm detection groups, create items, link to bin |
| `GET` | `/search` | Semantic vector search (`q`, `limit`, `offset`, `min_score`) |

The `/photos/{photo_id}/suggest` endpoint accepts an optional `?model=` query param to override the vision model per-request.

## QR Label Generation

Generate printable QR code labels for your bins:

```bash
cd api
uv sync --extra scripts

# Generate sequential labels BIN-0001 through BIN-0120
uv run python ../scripts/qr_labels.py --sequential --start 1 --count 120 --out ../labels.pdf

# Generate labels from bins already in the database
DATABASE_URL=postgresql+psycopg://binbrain:PASSWORD@127.0.0.1:5432/binbrain \
  uv run python ../scripts/qr_labels.py --from-db --out ../labels.pdf
```

## Development

### Running Tests

```bash
cd api
uv sync --extra test
uv run pytest tests/
```

Tests use an in-memory SQLite database and do not require Docker or Ollama.

### Running Locally (without Docker)

```bash
cd api
uv sync
DATABASE_URL=postgresql+psycopg://binbrain:PASSWORD@localhost:5434/binbrain \
  uv run uvicorn app.main:app --reload
```
